# MQ – Importadores Directos

Página web moderna y minimalista para MQ, empresa de importación directa de grifería y sanitarios metálicos.

## 🚀 Tecnologías

- **Next.js 14** - Framework React
- **React 18** - Biblioteca UI
- **TailwindCSS** - Estilos
- **Framer Motion** - Animaciones
- **TypeScript** - Tipado estático

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build

# Iniciar servidor de producción
npm start
```

## 🎨 Características
